# 📚 Tài nguyên tham khảo CUDA Learning

## Sách

### Beginner
- **CUDA by Example** – Jason Sanders, Edward Kandrot
  - ISBN: 978-0131387683
  - Sách nhập môn tốt nhất cho người mới

### Intermediate
- **Programming Massively Parallel Processors** (4th Edition) – David Kirk, Wen-mei Hwu
  - ISBN: 978-0323912310
  - Sách "kinh điển" về parallel programming

- **Professional CUDA C Programming** – John Cheng, Max Grossman, Ty McKercher
  - ISBN: 978-1118739327
  - Hướng dẫn toàn diện từ NVIDIA engineers

### Reference
- **The CUDA Handbook** – Nicholas Wilt
  - ISBN: 978-0321809469
  - Reference chi tiết về CUDA internals
